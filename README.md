# Huey 的工作台

一个无需后端的中文个人工作台，用于管理审核项目、待办事项和常用资料链接。

## 功能

- 项目新增、编辑、状态筛选、手动更新进度。
- 待办关联项目、设置日期和优先级、标记完成。
- 常用资料链接、分类管理及全局搜索。
- 本周安排视图和 JSON 数据备份、恢复。
- 桌面与手机布局。

## 数据与访问

网页可公开访问。你录入的项目、待办和链接保存在当前浏览器的 localStorage 中，不会自动上传到服务器或同步到其他设备。请定期在「数据与设置」中导出备份。

首次打开含明确标注的演示内容，示例项目与工厂均为虚构。可一键移除示例；编辑保存的内容与自行新增的内容会保留。

## 本地运行

在本目录运行：

```sh
python -m http.server 8765
```

打开 `http://localhost:8765/`。

## 验证

```sh
node --check app.js
node verify.cjs
```

## GitHub Pages

无构建步骤。在仓库设置中将 Pages 发布来源设为 `main` 分支的根目录 `/`。入口为 `index.html`，资源使用相对路径，适用于仓库子路径部署。
